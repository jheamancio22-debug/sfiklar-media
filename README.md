# SFI Klar media

Public hosting for **finished** SFI Klar social posts (videos, carousel slides, covers), so the scheduling tool (Metricool) can fetch them by URL.

- Only files that are scheduled or already posted go here. Drafts, specs and everything else stay in the private SFIKlar repo.
- Layout: `posts/<YYYY-MM-DD>/<HHMM>-<slug>/` with `video.mp4` or `slide-NN.png`, plus `cover.png`.
- Files are added by Claude's weekly publishing run.
